# RELATÓRIO TÉCNICO — VERSIONAMENTO SEMÂNTICO DO JOGO ROBO RUN 3D

## 1. Apresentação do projeto

O ROBO RUN 3D é um jogo de robótica desenvolvido para navegador, no qual o jogador controla um robô que precisa escapar de diferentes ambientes tecnológicos, como fábricas, data centers, armazéns autônomos e laboratórios de inteligência artificial. Durante a partida, o jogador deve desviar de obstáculos, saltar, deslizar e coletar núcleos de energia, buscando percorrer a maior distância possível.

O jogo possui renderização 3D por WebGL e oferece controles por teclado e toque, além de recursos como pontuação, recorde, pausa e reinício da partida.

Link do projeto: https://robotica-og9m.vercel.app/

## 2. Etapas de desenvolvimento

O projeto passou pela fase de desenvolvimento, na qual foram implementados os principais elementos do jogo, incluindo o personagem robótico, os ambientes virtuais, os obstáculos e as mecânicas de movimentação.

Após essa etapa, foram realizados testes para verificar o funcionamento das funcionalidades implementadas e identificar possíveis problemas. Posteriormente, o jogo foi publicado na plataforma Vercel, ficando disponível para acesso público pela internet.

## 3. Versionamento semântico

O versionamento semântico é uma convenção utilizada para identificar versões de softwares por meio de três números, no formato MAJOR.MINOR.PATCH.

- **MAJOR:** indica mudanças incompatíveis com versões anteriores.
- **MINOR:** indica a inclusão de funcionalidades compatíveis com a versão anterior.
- **PATCH:** indica correções de erros e pequenos ajustes compatíveis.

Na página publicada do ROBO RUN 3D, consta a identificação BUILD 0.3.0. Essa identificação demonstra o número de compilação apresentado pelo jogo, mas não confirma, por si só, qual é a versão semântica oficial do projeto.

Caso o jogo ainda esteja em desenvolvimento experimental, a versão 0.3.0 poderá ser utilizada como referência. Caso corresponda à primeira versão estável, testada e oficialmente disponibilizada ao público, recomenda-se a adoção da versão 1.0.0.
